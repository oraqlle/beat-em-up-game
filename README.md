## Controls

- `<WASD>` - Forwards, backwards, left and right strafing
- `<space>` - Jump
- `<left-click>` - Punch Attack
- `<right-click>` - Interact
- `<e>` - Throw bombs
- `<left-shift>` - Engage thrusters
